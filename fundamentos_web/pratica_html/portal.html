Semana Acadêmica de Tecnologia

O curso de Sistemas de Informação realizará uma Semana Acadêmica de Tecnologia com palestras, oficinas e atividades relacionadas à área de computação.

Maratona de Programação

Os estudantes poderão participar de uma maratona de programação para testar seus conhecimentos em lógica, algoritmos e desenvolvimento de soluções.

Processo seletivo para monitoria

Estão abertas as inscrições para o processo seletivo de monitoria. Os estudantes interessados devem consultar as informações disponíveis no portal acadêmico.
